# 🚀 Talkify

> AI-Powered Career Guidance Platform for personalized career path recommendations.

---

## 📖 Description

Talkify is an AI-powered career guidance platform that helps students and professionals explore career options, get personalized recommendations, and make informed decisions about their future. Using advanced AI algorithms, it analyzes user profiles and provides tailored career suggestions.

What makes it unique:
- AI-driven career path recommendations
- Interactive user interface
- Multiple page navigation system
- Theme customization support
- Comprehensive career exploration tools

---

## ✨ Features

- **AI Career Guidance** – Personalized career recommendations based on user profile
- **Interactive Exploration** – Browse and explore different career paths
- **User Profiles** – Create and customize personal profiles
- **Help & Support** – Comprehensive help section for users
- **Contact System** – Direct contact with career advisors
- **Theme Context** – Customizable UI themes

---

## 🧠 Tech Stack

**Frontend**
- React
- React Router DOM

- CSS3

**Deployment**
- GitHub Pages

## 🏗️ Architecture / Workflow

```text
User → Homepage → Profile Creation → AI Analysis → Career Recommendations → Exploration → Contact/Help
```

---

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/DevRanbir/talkify.git

# Navigate to project
cd talkify

# Install dependencies
npm install

# Start the project
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file and add:

```env
REACT_APP_API_KEY=your_api_key_here
```

## 🧪 Usage

* Step 1: Visit the homepage
